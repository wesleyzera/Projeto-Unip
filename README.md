# 🧠 SmartSupport – Plataforma Avançada de Gestão de Chamados com IA

---

## 📚 Visão Geral do Projeto

**SmartSupport** é um sistema inovador para gerenciamento eficiente de chamados técnicos, utilizando inteligência artificial para automatizar a triagem, categorização e resolução de incidentes. A plataforma visa otimizar o fluxo de atendimento e melhorar a experiência do usuário final.

Este projeto foi criado para a disciplina Projeto Unip 2025, turma 6º ADS.

---

## 📌 Desafio a Ser Resolvido

Criar uma solução tecnológica que permita:

- Gerenciar de forma centralizada os chamados técnicos das empresas.
- Classificar automaticamente os chamados utilizando IA para priorização.
- Fornecer sugestões de solução baseadas no histórico e análise de dados.
- Integrar-se com sistemas internos e bancos de dados das organizações.

---

## 🚀 Solução Implementada

O **SmartSupport** disponibiliza:

- Uma interface amigável para abertura, acompanhamento e fechamento dos chamados.
- Backend eficiente para gerenciamento das operações e integração com banco SQL Server.
- Algoritmos de IA treinados para reconhecimento e classificação dos tipos de chamados.
- Automação dos processos de atendimento, reduzindo o tempo de resposta.
- Ferramentas analíticas para geração de relatórios e monitoramento de KPIs.
